# WordSprout Kids 🌱

Flutter-first English vocabulary learning for children aged **4–6**.

## Implemented first slice
- Playful home and A–E alphabet path inspired by the approved UI concept
- Five letter-A learning subjects: ANT, APPLE, ARM, AXE, ARROW
- Word picture, speaking button, and exactly **three** narrated facts for each word
- Shuffled letter-tile spelling (duplicate letters use tile indices)
- Picture recognition and one fact-based check
- 3 starter words unlock the remaining 2 after mastery
- Locally persisted word completions and lightweight progress view
- Games area with clear locked status for parent-approved online features

**Current limitations:** The ant illustration is drawn as Flutter vector art; the other subjects use emoji placeholders until reviewed individual illustrations are supplied. Completion records are not a spaced-review mastery system yet. Online friends and games are not implemented. A–Z curriculum and letter checkpoint assessments are not yet implemented.

## Build locally
Requires a recent stable Flutter SDK.

```bash
flutter create --platforms=android --project-name wordsprout_kids .
flutter pub get
flutter run
flutter test
flutter build apk --release
```

The Android project scaffold is generated by `flutter create` because the repository begins as a minimal source project.

## GitHub Actions APK
Open **Actions → Android APK**. Once the workflow succeeds, download the `wordsprout-kids-release-apk` artifact.

## Safety
Local solo learning runs offline after installation. Friends/online game features are intentionally disabled until an authenticated guardian approval workflow, secure backend, and child privacy review exist.

## Design
Warm cream, layered greens, rounded buttons, large letter tiles, and no mascot. Art and screen hierarchy follow the accepted WordSprout four-screen reference.
